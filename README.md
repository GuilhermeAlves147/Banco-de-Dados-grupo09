# Banco-de-Dados-grupo09
# Projeto Final — Laboratório de Banco de Dados

## Visão geral

Sistema de marketplace que simula uma plataforma de comércio eletrônico, na qual usuários podem atuar como vendedores — cadastrando e gerenciando produtos organizados por categorias — ou como clientes, montando carrinhos de compra e finalizando pedidos. O projeto cobre o ciclo completo de banco de dados: modelagem conceitual e lógica, implementação física em MySQL, carga de dados, consultas de verificação.

## Tema

Marketplace (vendedores, clientes, produtos, categorias, fornecedores, carrinho e pedidos).

## Organização dos arquivos

O projeto possui duas pastas principais:

- **docs:** onde ficam os documentos relacionados ao trabalho.
- **sql:** onde ficam os códigos SQL utilizados no banco de dados.

Os arquivos SQL estão organizados da seguinte maneira:

- `01_ddl market.sql`: responsável pela criação do banco e das tabelas.
- `02_carga.sql`: utilizado para inserir os dados nas tabelas.
- `03_consultas.sql`: contém as consultas realizadas para verificar as informações.
- `04_05_view_perfil.sql`: contém as views e configurações de perfis.

## Como executar o projeto

Para executar o banco de dados, primeiro abrimos o MySQL Workbench e executamos o arquivo de criação das tabelas.

Depois, executamos o arquivo de carga para adicionar as informações ao banco.

Por último, utilizamos o arquivo de consultas para verificar os dados cadastrados e conferir se os resultados estão corretos.
